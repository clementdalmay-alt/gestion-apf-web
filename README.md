# Resident Activités — appli web

Page compilée de l'appli Resident Activités, publiée par GitHub Pages.
Ne contient aucune donnée : les données vivent dans un Google Sheet privé, lues et écrites par un service Google
qui vérifie la connexion et le rôle de chaque personne.

Le code source est dans un dépôt privé ; ce dépôt reçoit seulement le fichier assemblé (`index.html`). Ne pas modifier ici.
